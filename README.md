# claude-tools

[![tests](https://github.com/danfoley/claude-tools/actions/workflows/tests.yml/badge.svg)](https://github.com/danfoley/claude-tools/actions/workflows/tests.yml)
[![understand-first version](https://img.shields.io/badge/understand--first-0.14.5-blue)](understand-first/README.md)

A Claude Code plugin marketplace.

### Plugins
- [understand-first](understand-first/README.md): changes how Claude works with you so every piece of work ends with you understanding it, able to explain it back, and able to rebuild it without Claude. It starts small and ramps up slowly, in six stages.

### Install
```
/plugin marketplace add danfoley/claude-tools
/plugin install understand-first@claude-tools
```
